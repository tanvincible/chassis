# llms.txt

These docs as plain Markdown, for coding agents and other LLM tools:

- [llms.txt](https://tanvincible.github.io/chassis/llms.txt): what Chassis is, the rules that
  matter, and a link to each page
- [llms-full.txt](https://tanvincible.github.io/chassis/llms-full.txt): the guides, the Python,
  Rust and C references, the errors and an example, as one page
- Each page of this book: its address with `.md` in place of `.html`, as
  [guide/errors.md](https://tanvincible.github.io/chassis/guide/errors.md)

[Chassis for Coding Agents](./guide/agents.md) has a line to paste into an agent's rules that
points it at llms-full.txt.
